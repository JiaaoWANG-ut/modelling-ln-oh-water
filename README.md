# Ln(OH)₃ + 128 H₂O：水盒子与水滴初始模型（PBC / non-PBC）

为 UMA 1.2、MACE-OMOL、MACE-POLAR-1 三个模型准备的镧系离子水合初始结构，
覆盖 6 个中心离子 × 4 种边界条件 = **24 个结构**。

## 1. 体系组成

每个结构的组成完全一致：

```
Ln³⁺  +  3 OH⁻  +  128 H₂O   →   391 个原子，净电荷 0
```

净电荷为 0 是刻意设计的：`+3 − 3 = 0`。这样避免了带电周期性体系的
Ewald/补偿背景电荷问题，同时三个模型仍然需要正确的自旋多重度。

3 个 OH⁻ **全部放在 Ln³⁺ 第一配位壳内**（即中性配合物 `[Ln(OH)₃(H₂O)ₙ]`），
位置通过"使 3 个 OH⁻ 之间距离最大化"自动选取。

## 2. 四种边界条件变体

| 变体 | 几何 | 周期性 | 晶胞 |
|---|---|---|---|
| `box_pbc` | 立方水盒子 | 三维周期 | 15.782 Å |
| `box_nonpbc` | 同一坐标，视为有限立方团簇 | 无 | 无 |
| `droplet_pbc` | 球形水滴置于真空盒中心 | 三维周期 | 41.0–42.2 Å（真空间隙 22 Å） |
| `droplet_nonpbc` | 同一水滴，无晶胞 | 无 | 无 |

关键设计：**`box_pbc` 与 `box_nonpbc` 的笛卡尔坐标完全相同**，
`droplet_pbc` 与 `droplet_nonpbc` 仅相差一个整体平移。
因此 pbc / non-pbc 的对比是**固定几何下的纯边界条件测试**，
能量差完全来自周期性处理，不掺杂结构差异。

`droplet_pbc` 的真空间隙取 22 Å，超过所有目标模型的感受野
（MACE-POLAR-1-L 最大为 18 Å），所以它的结果应当与 `droplet_nonpbc` 一致——
这本身就是一个很好的自检。

## 3. 尺寸如何符合水的密度

**用溶剂的数密度定尺寸，而不是用总质量。**

131 个类水分子（128 H₂O + 3 OH⁻，两者摩尔体积基本相同）按
298 K 液态水密度 0.9970 g/cm³（= 0.033327 分子/Å³）：

```
V = 131 / 0.033327 = 3930.7 Å³
立方边长 L = V^(1/3)          = 15.782 Å
水滴半径 R = (3V/4π)^(1/3)    =  9.790 Å
```

Ln³⁺ 视为体积中性。这不仅是通用惯例，在这里还偏保守：
Ln³⁺ 的电致收缩使其偏摩尔体积实际为**负**（La³⁺ 约 −39 cm³/mol）。

⚠️ 若改用**总质量** / 0.997 来定盒子（V = 4157 Å³，L = 16.08 Å）会是**错误**的：
电解质溶液的质量密度本身就大于 1 g/cm³，而水并没有被膨胀。
本模型盒子内的溶液质量密度为 1.054 g/cm³（La），正是应有的结果。

最小镜像距离 L/2 = 7.89 Å，大于各模型单层截断（约 6 Å）。

## 4. 中心离子参数与自旋多重度

自旋取 4f ⁿ 自由离子 Hund 规则**高自旋**基态。这既是物理正确值，
也是 OMol25 唯一涵盖的情形——OMol25 论文明确说明镧系配合物**只计算了高自旋态**。

| 离子 | 4f ⁿ | 未成对电子 | **2S+1** | 电荷 | CN | d(Ln–OH⁻) Å | d(Ln–OH₂) Å | 壳内最短 O–O Å |
|---|---|---|---|---|---|---|---|---|
| La³⁺ | 4f⁰  | 0 | **1** | 0 | 9 (TTP) | 2.40 | 2.54 | 2.772 |
| Nd³⁺ | 4f³  | 3 | **4** | 0 | 9 (TTP) | 2.35 | 2.49 | 2.716 |
| Gd³⁺ | 4f⁷  | 7 | **8** | 0 | 9 (TTP) | 2.27 | 2.41 | 2.626 |
| Dy³⁺ | 4f⁹  | 5 | **6** | 0 | 8 (SAP) | 2.23 | 2.37 | 2.711 |
| Er³⁺ | 4f¹¹ | 3 | **4** | 0 | 8 (SAP) | 2.20 | 2.34 | 2.675 |
| Lu³⁺ | 4f¹⁴ | 0 | **1** | 0 | 8 (SAP) | 2.16 | 2.30 | 2.626 |

- 配位数按实验序列取值：轻镧系 CN = 9（三帽三棱柱 TTP），Dy 之后 CN = 8（四方反棱柱 SAP）。
  于是第一壳为 3 OH⁻ + 6 H₂O（CN 9）或 3 OH⁻ + 5 H₂O（CN 8）。
- OH⁻ 键长比同族水分子短 0.14 Å，因为 OH⁻ 是更强的给体。
- 电子数奇偶性已逐个校验：偶电子 ↔ 奇多重度。例如 Gd 体系共 1371 个电子（奇），
  多重度 8（偶），自洽。

## 5. 三个模型的调用方式

三个模型**都**从 `atoms.info` 读取净电荷与**自旋多重度（2S+1）**，键名相同：

```python
atoms.info["charge"] = 0     # 净电荷
atoms.info["spin"]   = 8     # 2S+1 = 未成对电子数 + 1
```

结构文件（extxyz）中已经写入 `charge`、`spin`、`spin_multiplicity`，
驱动脚本还会**从元素组成重新推导并校验**，不一致就报错。

```bash
cd mlip

# 先不加载模型，只检查结构 / 电荷 / 自旋
python run_uma.py --dry-run

# UMA 1.2（fairchem v2），omol 任务是唯一接受 charge/spin 的任务
python run_uma.py --model uma-s-1p2 --task omol "droplet_nonpbc/*.xyz"

# MACE-OMOL
python run_mace_omol.py --model extra_large --variants droplet_nonpbc

# MACE-POLAR-1（额外输出每原子电荷与总偶极）
python run_mace_polar.py --model polar-1-m --variants droplet_nonpbc
```

安装（本仓库不含模型权重）：

```bash
pip install fairchem-core          # UMA，权重需 HF 登录：hf auth login
pip install --upgrade mace-torch   # MACE-OMOL 需 >=0.3.14，MACE-POLAR-1 需 >=0.3.16
pip install git+https://github.com/WillBaldwin0/graph_electrostatics   # POLAR 长程项
```

### 使用时必须注意

1. **三个模型都是 OMol25（分子、非周期）训练的。** `box_pbc` 属于分布外使用；
   `droplet_nonpbc` 是最贴合训练分布的变体，建议以它为基准。
   UMA 若换用 `omat`/`omc` 任务可以处理周期体系，但那些任务**不读取 charge/spin**，
   Ln³⁺ 的自旋态就丢失了——脚本会对此发出警告。
2. **OMol25 对镧系配合物覆盖有限**，论文自己列为已知短板。结果应视为外推，
   建议至少对若干构型做 DFT 校验。
3. MACE-POLAR-1 目前**尚不支持 LAMMPS-MLIAP**。
4. 15.782 Å 的盒子对 3+ 离子偏小（离子与自身镜像相距一个盒长）。
   要研究离子的长程水合，应增加水分子数，而不是放大盒子（那会降低水密度）。

## 7. 复现

```bash
python build/build_systems.py --out structures      # 约 2 分钟
python build/validate.py --root structures --out reports/validation.md
```

建模流程分两阶段：

- **阶段 A（定氧原子位置）** 第一壳按理想 TTP/SAP 多面体解析放置；
  本体水先随机撒点，再用逐对推开迭代消除重叠；最后做"填洞"步骤，
  把局部过密处的分子搬到空洞里，消除中尺度密度不均。
  水滴不是直接在硬球壳内堆积的——那样墙壁会把表面分子往里推而无反作用力，
  导致外层欠密 20–30%。水滴是**从松弛好的周期液体中挖出来的**，
  并且挖取中心经过筛选，使其周围氧原子数正好符合体密度。
- **阶段 B（加氢）** 每个分子扫描候选取向，目标函数 = 硬球重叠罚函数
  − 氢键奖励（配位配体只剩绕 Ln–O 轴的一个自由度）。
  先顺序放置，再做多轮全局精修。

## 8. 校验结果

`reports/validation.md`：**24 个结构，0 项失败，0 项警告**。每个结构检查约 30 项，
包括：

- 组成与分子拓扑（由距离重建，不读建模程序的记录）：3 个 OH⁻、128 个 H₂O、无游离 H
- 键长 0.957–0.964 Å，H–O–H 角 104.52°
- 配位数与 OH⁻ 是否都在第一壳；第一壳外最近氧 > 3.55 Å（g(Ln–O) 第一极小）
- 最短分子间距离：O–O ≥ 2.63 Å、O–H ≥ 1.60 Å、H–H ≥ 1.80 Å
- 溶剂数密度 = 0.03333 Å⁻³（盒子按构造精确；水滴半径 9.63–9.79 Å vs 标称 9.790 Å）
- **最大空腔半径 2.92–2.99 Å**（网格扫描最大无氧球）。作为参照，
  该密度下理想晶格的最大间隙约 2.5 Å，因此此处不存在能再塞进一个水分子的空洞
- 氢键数：周期盒子 2.75–2.98 个/分子。氧位置固定时约 3.1 是上限
  （平衡态液态水为 3.5–3.6），non-pbc 变体更低是因为表面 O–H 没有受体——
  这正是该模型应有的物理内容
- 电荷、多重度、电子数奇偶性一致性

## 9. 已知局限

- 这些是**初始结构**，不是平衡构型。氧位置来自硬球式松弛而非四面体氢键网络，
  所以氢键数低于平衡态液态水。正式生产前建议先做几十 ps 的 MD 平衡。
- 水滴只有 131 个分子，半径约 9.8 Å。局部密度的统计噪声本身就有约 10%
  （一个 ~37 分子的球壳），而且体系内**不存在真正的"体相"区域**：
  溶剂要么在水合壳内，要么在表面。
- 第一壳几何取理想多面体（对称），未做 DFT 预优化。
- CN = 8 时 3 个 OH⁻ 中最近的两个相距 2.63–2.71 Å。这是几何必然
  （8 配位壳里放 3 个阴离子），且属于正常配体–配体接触距离，
  MD 一开始就会松弛开。
